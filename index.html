Cómo subir a GitHub y GitHub Pages

Este archivo único index.html contiene toda la aplicación de Three.js, shaders, estilos y el ViewCube CAD interactivo.

  1. Crea un repositorio nuevo en GitHub (por ejemplo: hollow-knight-cad).
  2. Sube este archivo renombrado estrictamente como index.html en la rama principal (main).
  3. Ve a la pestaña Settings de tu repositorio de GitHub.
  4. Entra a la sección Pages en el menú lateral izquierdo.
  5. En Build and deployment, selecciona la rama main y la carpeta root / (root), luego haz clic en Save.
  6. ¡Listo! En un minuto GitHub te dará el link web público para mostrárselo a tu profesor.
