Cómo subir a GitHub y GitHub Pages

Este archivo único index.html contiene la aplicación de Three.js, shaders, el ViewCube CAD y el cargador de archivos STL.

  1. Crea un repositorio nuevo en GitHub.
  2. Sube este archivo como index.html en la rama principal (main).
  3. Ve a la pestaña Settings > Pages.
  4. Selecciona la rama main y carpeta root / (root), luego Save.
